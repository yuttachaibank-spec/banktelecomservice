วิธีใส่รูปผลงาน / หน้าร้าน
==========================

นำไฟล์รูปจริงมาวางในโฟลเดอร์ "images" นี้ โดยตั้งชื่อไฟล์ให้ตรงตามนี้
(แนะนำรูปแนวนอน อัตราส่วน 4:3 ขนาดประมาณ 1200x800 px ไฟล์ .webp ไม่เกิน 150 KB)

  shop-front.webp    = รูปหน้าร้าน
  work-screen.webp   = งานเปลี่ยนจอไอโฟน
  work-battery.webp  = งานเปลี่ยนแบตเตอรี่
  work-board.webp    = งานซ่อมบอร์ด
  work-macbook.webp  = งานซ่อมแม็คบุค
  work-watch.webp    = งานเปลี่ยนจอ Apple Watch

* ถ้ายังไม่ใส่รูป ช่องแกลเลอรีจะแสดงไอคอนกล้องชั่วคราว (เว็บไม่พัง)
* ใช้ภาพถ่ายหน้าร้าน ช่าง เครื่องมือ และผลงานจริงของร้าน ไม่ใช้ภาพสต็อกหรือภาพสร้างด้วย AI
* พอวางไฟล์ครบแล้ว รูปจะขึ้นอัตโนมัติ ไม่ต้องแก้โค้ด
* อยากเพิ่ม/ลดจำนวนรูป แก้ได้ในส่วน <!-- GALLERY --> ของไฟล์ index.html
